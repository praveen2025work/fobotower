What the dates depend on

Raise these now (long lead)

  • UAT and Prod platform requests (Prod needed by 11 Dec)
  • Network access to MB Rec, MOTIF, FAS and the LLM gateway
  • Model and data approval for the LLM gateway
  • DPIA, AI risk assessment and penetration test slot
  • MB Rec extra data and end-of-day trigger; FAS test access
  • Diagnostics hosting outside AWS/BCP

Assumptions

  • Team: 2 backend, 1 DevOps, 1 QA, 1 BA, PM and architect; frontend part-time; Product Control SME part-time
  • Product Control available for set-up in S1–S2 and UAT in S4–S5
  • Change freeze 11 Dec – 4 Jan: Prod built before it, released on 5 Jan
  • Users are already provisioned and testing their skill in finance agent chat

Top risks

  • Prod not ready by 11 Dec: platform and network requests are the critical path
  • The build deployment is failing today; fix in progress
  • Posting adjustments to MOTIF through FAS needs controls sign-off and FAS access in UAT
  • Late approvals (model, DPIA, penetration test, CAB): each week late moves go-live by about a week

Ways of working

Definition of Ready

  • Written as a user story (As a … I want … so that …) with a clear title
  • Acceptance criteria agreed with the person who will accept it
  • Dependencies known and linked; none blocking the sprint
  • Estimated by the team (story points)
  • Fits in one sprint; split if not
  • Environment, data and access needed are available

Definition of Done

  • Acceptance criteria met and shown to the person who accepts it
  • Code reviewed, merged and built by the pipeline; tests and security scans pass
  • Deployed to UAT (or Prod where the story says so)
  • No open Sev1/Sev2 defects against the story
  • Documentation, runbook or Confluence page updated where affected
  • Jira status, links and time spent up to date

Jira conventions

  • Stories are written as user stories with acceptance criteria; Given / When / Then where there is behaviour to test
  • Releases: R1 Working version (30 Nov 2026) R2 Go-live (14 Jan 2027)
  • Components: Programme, Platform, Agent One, Connections, FOBO, Diagnostics, Risk and controls, Testing, Engagement, Go-live
  • Dependencies are “is blocked by” links between stories
  • Points on the Fibonacci scale (1, 2, 3, 5, 8); two-week sprints
